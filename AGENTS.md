# Scientific integrity

This public repository is authorized by the user's direct request. Preserve all
negative, null, contradictory, failed and invalid experiments. Never tune on held-out
performance or describe finite tests as a proof. Keep raw trajectories, benchmark
issue text, original manuscript and credentials out of Git. Only publish compact
derived measurements, source URLs and content hashes. Do not execute downloaded
patches or commands. No paid model calls, cloud provisioning or fresh agent runs.
Both predictors use repository and issue length only. Future/rejected outcomes
must not enter admitted-only training. Report modeled time separately from measured
latency, and independent implementation separately from independent data.
