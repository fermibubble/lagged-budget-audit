# Lagged budget audit

Independent numerical checks and recorded SWE-agent trace replay for *Online
Knapsack When the Price Lags*. This is an audit, not a claim that every original
paper result has been reproduced. Public release authorized 2026-10-16.

The original starter and manuscript match the hashes recorded in
`docs/EXPERIMENT_PROTOCOL.md`. Raw archives and the original manuscript remain
local. No model calls or fresh SWE-agent runs are made.

The experiment protocol is frozen before held-out replay. Results, reproduction
commands and a revised manuscript will be added after execution. No open-source
license is selected on the authors' behalf.
